SEO generation workflow ↗

SEO pages are updated by GitHub Actions on an hourly schedule, not immediately after you publish. A valid sitemap does not guarantee Google indexing. Project-level robots.txt is not the host-root robots.txt.

Owner launch verification

These steps need your actual Supabase and Google accounts. Automated checks do not mark them completed.

  1. Database security: Open read-only RLS audit SQL, then run it inside the Supabase SQL Editor. Review RLS policies, grants, SECURITY DEFINER functions, and the image bucket. Do not paste keys or credentials into reports.
  2. Real Admin test: sign in as Super Admin, create one temporary draft, publish and edit it, check the public page, then delete that test article. Wait for the hourly SEO build before judging the generated article URL.
  3. Search Console: Add Domain property for https://cozyloops.site/, verify ownership, and submit sitemap.xml. Indexing is not automatic.
  4. Legal and recovery: publish valid contact details; review Privacy and Terms, and confirm Supabase backups and GitHub access.
